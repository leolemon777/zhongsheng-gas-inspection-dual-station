# 开发规范与协议核对

## 中盛 RJ45 模块协议

- 通信默认参数按说明书：IP `192.168.0.7`，端口 `8234`，站号 `1`。
- 现场接交换机前必须先逐个修改模块 IP，避免两个默认 `192.168.0.7` 模块冲突：
  - 工控机建议 `192.168.0.100`。
  - IO 模块建议 `192.168.0.10:8234`。
  - 模拟量模块建议 `192.168.0.11:8234`。
- 软件支持两种现场模式：
  - 标准 Modbus TCP：MBAP 头 + PDU。
  - RTU over TCP：站号 + 功能码 + 数据 + CRC16，CRC 低字节在前。
- 数字量输出只用线圈协议：
  - `01H` 读取线圈状态。
  - `05H` 写单个线圈。
  - DO1 协议地址为 `0000H`，DO2 为 `0001H`。
  - 输出开启写 `FF00`，输出关闭写 `0000`。
  - 当前自保持三线进气阀使用双 DO 脉冲：DO1=打开线，DO2=关闭线，默认脉冲 `500ms`。
  - 发打开脉冲前先确保 DO2 关闭；发关闭脉冲前先确保 DO1 关闭；禁止 DO1/DO2 同时输出。
- 数字量输入只用离散输入协议：
  - `02H` 读取离散输入。
  - 当前 IO 模块为 RJ45 4IO，只显示和读取 DI1-DI4 / DO1-DO4。
  - DI1 协议地址为 `0000H`，DI2 为 `0001H`。
- 模拟量输入只用输入寄存器协议：
  - `04H` 读取输入寄存器。
  - AI1 协议地址为 `0000H`，对应 PLC 地址 `30001`。
  - 原始值先按说明书解析为采样电压。
  - 4~20mA 电流换算：`mA = V / 249 * 1000`。
  - 压力按配置量程做线性换算。

## 气检流程

- 启动后按顺序执行：关闭进气阀脉冲 -> 打开进气阀脉冲 -> 充气 -> 关闭进气阀脉冲 -> 稳压 -> 采集 P1 -> 保压 -> 采集 P2 -> 计算漏率 -> 判定。
- 当前现场版本不写排气阀输出，排气由人工手动完成。
- 漏率公式固定为：`(P1 - P2) / P1`。
- 实际漏率大于允许漏率判定 NG，否则 OK。
- 停止、异常、流程结束必须发送进气阀关闭脉冲。
- 排气动作只发送进气阀关闭脉冲并提示现场手动排气。

## WPF 开发红线

- 启用 nullable 和警告即错误。
- 使用 Generic Host + DI 启动窗口。
- `MainWindow.xaml.cs` 只保留 `InitializeComponent()`。
- ViewModel 使用 CommunityToolkit.Mvvm 源生成器。
- 跨硬件、配置、数据存储调用必须经过接口或可替换服务。
- 不使用 `.Result` / `.Wait()` 阻塞 UI。
- 不在 ViewModel 直接 new Window 或弹 MessageBox。
- 配置和检测记录保存在项目目录 `Data` 文件夹，不能再写入 C 盘 AppData。
- 关键按钮保留 `AutomationProperties.AutomationId`，方便后续 UI 自动化测试。
- 全局异常处理覆盖 UI 线程、非 UI 线程、未观察 Task。
